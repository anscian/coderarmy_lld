## Problem
Business logic must be separate from object creation logic to reduce Client code complexity

## Factory Design Pattern
Create a separate class responsible for creating object.
Types of factory:-
- **Simple Factory**: a factory class that decides which concrete class to instantiate
- **Factory Method**: defines an interface for creating objects but allows subclass to decide which class to instantiate
- **Abstract Factory Method**: provides an interface for creating families of related objects without specifying their concrete classes
