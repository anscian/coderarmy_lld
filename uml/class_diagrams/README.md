| Relationship | Representation | Meaning |
| :---: | :---: | :---: |
| Inheritance | A `<\|--` B | B inherits from A |
| Composition | A `*--` B | B is a part of A, lifecycle tied to A |
| Aggregation | A `o--` B | B is a part of A, lifecycle independent |
| Association | A `-->` B | A references/uses B |
| Realization | A `<\|..` B | B implements interface A |
| Dependency | A `..>` B | A depends on B |
| Link (Solid) | A `--` B | Direct Connection |
| Link (Dashed) | A `..` B | Weak visual connection |
