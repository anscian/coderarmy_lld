| Representation | Signal Type |
| :---: | :---: |
| `->>` | Synchronous (waits for response) Request |
| `-->>` | Synchronous Reponse |
| `-)` | Asynchronous Request |
| `--)` | Asynchronous Response |
| `-x` | Failed Asynchronous Request |
| `--x` | Failed Asynchronous Response |
| `->` | Solid Line |
| `-->` | Dotted Line |
